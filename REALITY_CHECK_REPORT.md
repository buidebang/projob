### 🛠️ REQUIRED SYSTEMIC UPGRADES

To bridge this gap and compete with the top 1% of viral content, the following architectural fixes are mandatory:

**1. `lib/processing-orchestrator.ts` - Fix the Slicing & Throttling Flaws**
*   **The Slicing Fix:** Instead of blindly enforcing hard character limits (`chunkSize`), the `sliceInput` function must utilize an AI summarization pass or semantic chunking to preserve narrative context, or simply pass larger contexts and rely on the model's `max_tokens` and system prompts for structural density.
*   **The Throttling Fix:** When `length_reduced_by_80_percent` is active, the System Prompt inside `ProcessingOrchestrator` must be aggressively modified. Instead of just appending "limit to 2 paragraphs," it needs explicit directives: *"You are in high-efficiency mode. You MUST extract only the absolute highest-entropy insights. Condense into a flawless, punchy structure. NEVER abruptly truncate. Ensure perfect platform-native formatting within the constrained length."*

**2. `lib/ai/compiler.ts` & AI Prompts - Eradicate Rigid Templates**
*   **The Templating Fix:** Any static strings prepended or appended to outputs must be deleted.
*   **Dynamic Formatting:** The responsibility for platform-specific formatting must be entirely offloaded to the LLM via strict System Prompts (RAG Knowledge Base).

**3. System Prompts (RAG / AI Gateway) - Enforce "Masterpiece" Constraints**
The `AIGateway.injectSearchGroundingIntoPrompt` and the base system prompts in `ProcessingOrchestrator` need massive upgrades to enforce 2026 constraints:
*   **Reddit/Quora:** *Directive:* "Adopt a first-person, experiential tone ('I learned this the hard way'). Ban formal corporate buzzwords. Write like a cynical industry veteran."
*   **Twitter (X):** *Directive:* "STRICT ZERO OUTBOUND LINK POLICY in the main body. Generate high-entropy, scroll-stopping hooks without generic emojis. Use ghost linking ('Link in next post')."
*   **Dark Social (Discord/Telegram):** *Directive:* "Output strictly in Markdown rich-media format. Use structural headers like '[PAYLOAD]' or '[ALPHA DROP]'. Optimize for immediate peer-to-peer bot scraping."
*   **YouTube/Instagram:** *Directive:* "Front-load the most controversial/valuable hook within the first 15 words. Structure as a high-retention script."
